# GeoDiff 构象质量评估：按采样来源配对

Status: resolved

本次只交付 COV/MAT。性质工单按用户决定关闭为 `wontfix`，不再是套件接入条件。

## Problem Statement

模型的训练和生成已接入套件，但生成构象与参考构象的吻合程度、以及构象集合的量化性质误差尚无套件侧评估入口。独立 Paddle 镜像一次临时兼容试验能算出性质值，不等同于与作者 Torch 端对齐，也不能证明可直接交付。用户要求两项各做一次可控尝试，不让附加评估改变原有训推或拖入外部依赖排障。

## Solution

以公开离线命令为验收接口：输入作者格式的便携参考构象 NPZ 和写有来源字段的新 SDF，输出双向 COV/MAT、纳入与过滤数量、立体差异诊断。新 SDF 写出时从输入分子图计算来源，不从生成坐标反推。不得改采样数值或改造原始数据来凑配对。

## User Stories

1. 作为构象生成用户，我想用现有的 SDF 和参考构象做比较，而不用安装 Torch 或提供 Python pickle。
2. 作为评测者，我想按作者的分子划分归集构象，同时区分不同分子，避免比较错对象。
3. 作为评测者，我想明确看见纳入、跳过或无法匹配的分子数和原因，以免空集合也被报告成好成绩。
4. 作为 QM9 或 Drugs 用户，我想获得参考到生成、生成到参考两个方向的 COV 和 MAT，知道覆盖率的阈值、匹配距离的单位及样本预算。
5. 作为评测者，我想在输入数量超过作者采样预算时按原输入次序截取，不足时按作者规则统计排除，不复制构象补数。
6. 作为评测者，我希望看见生成构象与输入立体身份是否一致，而不改变样本归属或挑选指标更好的构象。
7. 作为审核者，我想核对未经修改的 Torch 作者基准与公开命令的结果。
8. 作为维护者，我想让常规训练、采样、已有四个候选包以及其他模型照常使用，不覆盖已有结果，不上传、不自动提交套件改动。
9. 作为贡献人，我想在需要改默认依赖、工具链或参考口径前就收到阻塞说明，据此决定是否继续。

## Implementation Decisions

- 每个新 SDF 构象携带 `GEODIFF_SOURCE_SMILES`，值为输入分子图在写入生成坐标前的规范异构 SMILES。评估按来源找到作者的参考分子集合，并核对生成记录与来源的原子顺序、显式氢和共价键。不推断缺失的标签。读回立体身份相异只计数，不剔除也不改变坐标。参考组一律按作者方式计分：首行参考记录的分子图为模板，组内全部参考记录的坐标都算参考，行间差异不触发拒绝。
- COV/MAT 使用现有 RDKit 依赖。默认不做力场优化，去氢后的最佳对齐 RMSD（Å）；按作者连接性过滤、默认每个参考构象对应两个生成构象，先过滤再截取。分别按参考轴和生成轴求最小值，以包含等号的作者阈值计算覆盖率，以两个方向最小距离的均值计算匹配距离；按分子等权汇总均值、中位数、总体标准差。
- 不改套件默认环境、训练器和权重包，不改 Torch 参考，不引入量化后端。采样与评估分组都与作者 `test.py` 的逻辑一致（2026-11-25 用户决定）：每个分子用首行分子图一次生成 `参考数 × num_confs` 个构象，默认 `2x`。实现及测试留在当前套件集成工作树，不创建套件提交、远端分支、PR 或上传。

## Testing Decisions

- 最高验收接口是公开离线评估命令：从实际参考 NPZ 和生成 SDF 读入，输出含分子数量、单位的机器可读结果。Torch 对照从同一份序列化后的数据读值，两端用相同拓扑、原子顺序、阈值、构象顺序；不把 SDF 写出时的坐标舍入混进框架差异。
- COV/MAT：至少一张真实分子图、非方形且两方向有区别的参考/生成集合（例如 2×4，另用一份多余生成构象检验截断）；至少一个筛除用例。检查作者的逐分子两向覆盖数组、匹配值和汇总，不只看形状。覆盖与计数精确，RMSD/MAT 在相同 RDKit 与相同坐标下 `atol=1e-8 Å, rtol=0`。
- 用真实反转构象验证按来源归组和计数，用负例验证旧 SDF、错误来源、两个作者分组共用同一来源以及生成记录与来源拓扑不符时报错；行间不一致的参考组照常计分。未经修改的作者程序和公开命令读同一份序列化坐标；对拍测试数据不用于论文成绩。

## Out of Scope

不做整套测试集、论文成绩复现、重新训练或精度对齐整个去噪器；不改训练器、模型数学、权重/数据包、下载、CINN 或测速，采样默认值以作者为准。性质数据仅供本地试验，不并入两套构象数据包。没有权限提交或推送 PaddleMaterials、更改第三方或扩充全套件必装依赖。

## Further Notes

性质评估停线的历史证据保留在独立工单，不带入 COV/MAT 的执行面。

COV/MAT 工单已于 2026-11-25 解决：公开命令与作者评估器读同一份 SDF，四组输入对齐。评审代理建议的排除开关按用户同日补充的复现原则（只做复现，不自行加功能、不替作者修 bug）未保留。同日用户裁定采样与评估逻辑都与作者原实现保持一致：采样改为每个分子用首行分子图一次生成参考数两倍的构象；评估不再拒绝行间不一致的参考组。模型质量只看前向输出的浮点级对齐和训练对齐，两者此前已实现，不需要另外证明。
