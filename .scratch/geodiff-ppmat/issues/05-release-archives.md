# 定版并交包

Status: resolved

## What to build

交付真实可用的原生权重包和完整作者切分的数据包，以及让使用者能复现训练和采样的英文用法说明。

## Acceptance criteria

- [x] 两个实际 ZIP 解包后，经套件加载权重、数据和最终配置，跑通小批训练与短步采样；验证没有缺键、多余键、布局或格式差异。
- [x] 权重包四名一致，数据独立分发；地址不固化在包内。两包就地交用户，资产不入库、不自动上传。
