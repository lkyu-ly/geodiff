# Domain Docs

GeoDiff is a single-context project. Before exploring, read `GLOSSARY.md` at the project root and relevant decisions in `docs/adr/` if they exist. If either is absent, proceed silently; `/domain-modeling` creates them when terminology or decisions are settled.

Use the glossary's vocabulary in issues, designs and tests. Flag conflicts with existing ADRs explicitly rather than silently overriding them.
