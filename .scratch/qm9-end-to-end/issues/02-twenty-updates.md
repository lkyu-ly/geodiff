# 02: 同批次同随机输入 20 步训练

Status: ready-for-agent
Blocked by: None

用各端原生权重和新双 Adam 做 20 次训练更新，按步骤比较损失。

- [ ] 从 L1 的 flat batch NPZ 生成一份共享输入包，首步保持原样，后续 19 步固定 NumPy 乱数；Torch 和 Paddle 分进程复用该输入包。保留实验工具之外的模型和训练入口。
- [ ] 复用现有 loss replay、原生双 Adam 与全模型裁剪，每步打印并保存更新前总 loss / 子 loss、裁剪前梯度范数和两路 LR；无验证与历史状态恢复。
- [ ] 比较器保存 20 行对照，统计三个 loss 的绝对/相对误差和有符号范围，严格用总 loss 跨零给出结果。小例验证输入包第一步逐位保持，以及跨零、单侧和缺步/非有限异常。保留固定证据，记录复现命令。
