# 套件构建与固定去噪

Status: resolved

## What to build

通过套件工厂构建 GeoDiff、读取原生权重及 GEOM-QM9 图批次，复用经比对仍保持原数值语义的公共功能。

## Acceptance criteria

- [x] 样本、原子、键及拼批偏移正确；有序扩展边、掩码和两路固定去噪分数对拍通过。
- [x] 复用候选先经实际前向、损失和梯度检查，扩散表与共享权重布局不变；不引入 Torch/PyG。

Blocked by: 无（独立工作树准备好后可开始）。

参考：[接入规格](../spec.md)、[对应任务](../plan.md#任务套件构建与固定去噪)。

## Comments

`feat/geodiff`：Paddle 3.4.0 无 Torch 环境，两个数据拼批用例通过。RTX 4060 Ti、FP32 下实际接入版本的 198 个状态键和值、98 个共享别名一致；固定输入 Global/Local 分数最大绝对差为 `5.96e-7 / 4.77e-7`，边及掩码精确相同。64 条构象回放的 89 个梯度通过容差，两步反向更新的三个模式均通过。只在等价检查后使用公共归约和接受原 beta 数组的建表路径。

**2026-11-26 复用补全**：`GINEConv` 改为继承套件的 `MessagePassing`（`ppmat/models/common/message_passing/`），与作者原码继承 PyG 同名基类的写法一致，权重键不变。CPU 上用 QM9、Drugs 发布权重对 6 组固定输入做改前改后对比，分数、边、损失、全部参数梯度和两步采样坐标共 597 个数组逐位相同。其余第三方转换代码在套件里没有等价实现可复用。两份预设与发布权重里保存的作者配置逐项一致（模型键无差异，`max_iters` 10000000；两份权重分别停在 2,865,000 和 2,415,000 步）。
