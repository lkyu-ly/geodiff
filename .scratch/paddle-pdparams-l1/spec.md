# GeoDiff Paddle：原生 .pdparams 权重与 L1 梯度对齐

Status: resolved

## 问题与目标

上一轮用离线 NPZ 作为 Paddle 权重的中间格式，训练验收只覆盖了"同权重冒烟"，尚不能回答 Paddle 的反向传播和 loss 是否与 Torch 等价。发布给 PaddleMaterials 需要原生 `.pdparams`；精度验证需要两侧各加载自己的原生检查点，并在完全相同的输入上比较 loss 与梯度。

## 使用场景

1. 维护者运行一次性脚本，把作者发布的 Torch 权重转换成 `qm9_default.pdparams`；转换过程逐项核对键、形状、dtype 和数值，不依赖 GPU。
2. 使用者用 `paddle.load` 加载发布权重，模型、采样、前向检查与训练冒烟都走同一条路径；NPZ 权重格式及其导出子命令删除。
3. 迁移者让 Torch 回放已录制的首步训练输入，保存逐参数梯度，再把同一批次、时间步、噪声喂给 Paddle。
4. 迁移者比较两侧 loss、梯度范数、每个参数的梯度，得到训练精度的第一个结论；该步骤不涉及优化器。
5. 后续优化器状态转换（单步更新、五步续训）作为独立规格，依据本规格的 L1 结果再定。

## 已确认的实现决定

- 一次性脚本在独立 Torch 进程读取可信 `.pt`，构建 Paddle 骨架得到目标键、形状、dtype，按目标层类型转置且仅转置 Linear 权重（含方阵与共享别名），用 `paddle.save` 写出仅含模型权重的 `.pdparams`。不写入 config、迭代号或优化器状态。脚本保留在仓库，发布权重文件不入库。
- Paddle 侧发布权重统一通过 `paddle.load` 读取，再交给现有的严格校验（键、形状、dtype、别名值一致，先校验后写入）。删除 NPZ 权重读取函数、导出器的 `weights` 子命令以及文档中所有 NPZ 权重命令；数据集 NPZ 不受影响。
- Torch 侧新增一次性回放脚本：加载官方 `.pt` 和已录制的首步输入，按录制的 `time_step` 与 `pos_noise` 计算扰动位置，只做一次前向和反向，不更新参数；保存逐原子两路 loss、总 loss、裁剪前全局梯度范数，以及每个命名参数的梯度（含无梯度参数名单）。Torch 模型沿用已确认的 GIN 非原地 shortcut 补丁，结果标注为当前 Torch 环境下的对照。
- 首步输入批次的 64 条构象从官方训练集导出成数据 NPZ，原子、键、类型顺序与 Torch 录制一致。Paddle 回放脚本用同一批次与噪声走同一扰动和损失公式，输出同样结构的结果文件。
- 比较在 CPU 上用 NumPy 完成：边索引、边类型、局部掩码要求完全相同；逐原子 loss、总 loss、梯度按 `atol=1e-4, rtol=1e-3` 比较，并报告最大和平均绝对误差、相对误差及逐层范数比。该容差针对 float32 GPU 上反向归约的舍入差异，运行前固定，失败先定位原因，不事后放宽。
- 验证损失不在本规格内：历史 Torch 验证未录噪声，需另录；本规格只对齐训练 loss 与梯度。

## 验证界面与验收

- 权重转换：脚本输出与官方 `.pt` 的 198 个条目逐项一致（Linear 转置后），Paddle 加载后 `state_dict` 与文件逐项一致，固定输入前向保持上一轮结果（边完全一致，两路分数在 `atol=1e-5, rtol=1e-4` 内）。
- L1 对齐：Paddle 回放输出的边数组与 Torch 完全一致；loss 与梯度在上述容差内；输出一份可读摘要，列出每个命名参数的最大绝对误差与相对误差。无梯度参数集合两侧相同。
- 入口回归：训练冒烟与采样加载改用 `.pdparams` 后通过原有用例；默认 `pytest` 全绿，测试不依赖 `PYTHONPATH`。
- 只运行与改动相关的用例，不跑完整数据集、Drugs 或扩散采样；不上传权重、数据或运行产物。

## 不在本规格范围

单步 Adam 更新对齐、五步续训对齐、双调度器状态转换、验证损失对齐、PaddleMaterials 注册与 CINN。
