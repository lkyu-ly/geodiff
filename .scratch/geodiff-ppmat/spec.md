# GeoDiff QM9 接入 PaddleMaterials

Status: needs-info

本地接入、验收和交包完成；仅[回填并验证正式链接](issues/06-release-links.md)等用户提供地址。

## 目标

在从 PaddleMaterials `upstream/develop` 派生的独立工作树中，接入已验收的 GeoDiff QM9 Paddle 镜像。用户能通过套件构建模型、读作者的 QM9 切分、加载发布权重、训练及恢复原生断点，并从有键分子图生成三维构象。验收后将权重包和数据包交用户，收到正式链接后验证套件的按名加载与数据获取。

## 已确认约束

- 首版只交付作者的 GEOM-QM9 配置和单卡 FP32 动态图训推；不加入 Torch/PyG 运行时依赖、CINN、测速、Drugs、测试集生成指标或历史 Torch 优化器恢复。
- 公共训练扩展须显式启用，旧模型和配置保持原行为；公共框架改动验证后可单独做一次本地提交，仅此范围。
- 公共归约和扩散建表只在证明等价后换用，且只改 GeoDiff 的调用；保留原构图、加噪、反向更新及发布权重的参数和缓冲区布局。其他核心数值改动须用户确认。
- 在现有 `structure_generation/sample.py` 添加显式的有键分子图模式，读 QM9 NPZ、输出保留原子和键的 SDF；保留现有晶体模式，不新增 SMILES 等输入格式。
- 权重包和数据包在内容与接口验收定版后分别放在 GeoDiff 根目录，由用户手动交给维护者；正式链接只写到包外的套件登记。
- 未经用户明确授权，PaddleMaterials 其余改动留在工作树；不推送至 fork 或官方仓库，PR 由用户手动创建。

## 接入契约

- **数据与模型。** 保留作者原训练、验证和测试切分、样本及原子顺序、显式氢和共价键编号。沿用现有 NPZ（含 `node_ptr`、`edge_ptr` 和按用途读取的分子元数据）；在套件侧用 `atom_types`、`cart_coords`、`edge_index`、`edge_type` 及节点数，优先复用 `Data`、`Batch`、`DefaultCollator` 和加载工厂。不换同名的性质预测数据集，不把原子序数或键编号改成词表索引。一个模型实例持有原版状态，继续按原顺序在带噪坐标上构图，保留类型为 0 的半径边和边编码的共享关系。
- **训练。** 复用标准 Trainer，一次反传总损失、一次按全模型裁剪、两路 Adam 各更新其参数。Global 和 Local 的 Plateau 分别使用验证集中各自按原子加权的均值。沿用可调日志，保留总损失、两路损失、裁剪前范数、两路学习率；对齐逐步打印、不写 TensorBoard。原生续训恢复两组优化器和调度状态；作者权重只初始化模型。
- **采样。** 由 `MolecularSampler` 编排，模型按有键图从随机坐标生成构象。默认每条输入图生成一个构象，可配置数量；保持输入记录顺序与图内原子顺序，输出相同分子的键及三维坐标。支持本地配置和原生权重，正式发布后也支持注册名。首版不把同分子的输入记录自动去重，不依赖参考构象数量或测试指标。
- **交付。** 使用公共 `load_pretrain`；在验证中另查缺键、多余键、形状、数据类型、共享关系和扩散表。权重包名、顶层目录、配置名和注册名统一为 `geodiff_qm9_default`，包内有 `checkpoints/best.pdparams`。完整作者切分的数据包单独交付，走套件已有数据下载和 MD5 校验；两包不入代码仓。先用本地解包产物验证，再领取正式链接。英文模型 README 提供模型图或来源、数据获取、训练与采样命令和引用；精度对齐证据放 PR，不作为本文档宣称的生成质量。
